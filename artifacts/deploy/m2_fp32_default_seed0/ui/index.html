How these are computed

Each test picture is run twice: once through the original model (negative, should not be flagged) and once through the current, corrupted model (positive, should be flagged). TP = corrupted and flagged, FN = corrupted and missed, FP = original and flagged, TN = original and not flagged. Recall = TP / (TP+FN), precision = TP / (TP+FP), F1 = 2·P·R / (P+R), F2 = 5·P·R / (4·P+R), false-alarm rate = FP / (FP+TN). F2 counts recall four times as much as precision, because for a fault monitor a missed corruption is worse than a false alarm. Precision, F1 and F2 depend on the 50 / 50 mix used here; recall and false-alarm rate do not. With a weight format other than FP32, "original" means the model in that format before any flips, so the format change alone is never counted as a detected fault. A fault that leaves an answer unchanged is not harmless in itself, but it cannot be seen from the answer, so it is reported separately and never mixed with changed answers.

Layer by layer: besides the main monitor (one SVDD over all layers together), every observed layer has its own SVDD and its own threshold, both fixed on healthy calibration pictures at the same allowed false-alarm share. A layer's "flagged" rate is its alarm rate on the corrupted model; its "false alarms" are on the model before flips. "Alarms first" is the earliest layer, in the order the picture flows through the network, that is over its threshold. A flipped weight changes the activations of the next observed layer first, so that is where the orange frame goes. Because each layer may false-alarm at the allowed share on its own, "any layer" false-alarms more often than the main monitor.

    How this was measured

    Every design is an SVDD (one-class SVM, RBF kernel) fitted on healthy pictures only, with its settings and its threshold chosen on healthy calibration pictures, so no fault ever shaped a detector. Single layer: one SVDD watching one layer. Per layer: one SVDD per layer, each score turned into "how unusual compared with healthy pictures", then combined by the most unusual layer (max), the average (mean) or a weighting by each layer's false-alarm rate. Subset: one SVDD over the joined features of a group of layers, grouped by position, by leaving one layer out, or added one at a time by lowest false-alarm rate on healthy data. Joint: one SVDD over all layers. Detection rate is the share of corrupted inferences flagged when the threshold allows the chosen share of false alarms; ranking quality (AUROC) is the chance that a corrupted inference scores higher than a healthy one, 50 % being a coin toss. Differences come with a 95 % interval from resampling whole injections; an interval that contains zero is "no detected difference". Cost is the time to score one picture once its layer features exist; observing more layers also costs more feature extraction, shown in the facts above.
